# Security policy

## Reporting a vulnerability

Send security reports privately to `bok@hens.farm`.

Include the affected contract, transaction or block where relevant, a clear description of the issue, its potential impact and reproducible steps. Please allow a reasonable period for investigation and remediation before any public disclosure.

Never include private keys, seed phrases or other wallet credentials in a report.

## Official verification

The official website is [hens.farm](https://hens.farm). Contract addresses are published in [`deployments/robinhood-mainnet.json`](deployments/robinhood-mainnet.json) and linked to the public explorer from the repository README.
